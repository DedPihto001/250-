# IMDb Top 250 в SQLite

`main.py` загружает список IMDb Top 250 и сохраняет его в `imdb_top_250.db`.
Таблица `movies` содержит ранг, идентификатор IMDb, название, год, рейтинг,
жанры, режиссёра и ссылку. Жанры хранятся в SQLite как JSON-массив.

## Запуск меню в Windows PowerShell

```powershell
cd "C:\Users\Lenovo\Desktop\Course\250-imdb"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Меню позволяет искать по слову в названии, выводить топ-10 фильмов строго
после 2015 года и сравнивать точное совпадение `=` с частичным `LIKE`.
Удаление фильмов до 2005 года запрашивает подтверждение, затем выполняет
`VACUUM`. В SQLite `LIKE` ищет совпадение по шаблону (здесь без учёта регистра
для ASCII), а `=` сравнивает полное значение.

Чтобы обновить таблицу свежим IMDb Top 250 вручную, выполните
`python main.py --scrape`. Это заменяет содержимое таблицы и вернёт записи,
удалённые в ходе задания.

База в этом репозитории уже подготовлена: фильмы с `year < 2005` удалены,
после чего выполнен `VACUUM`.

Для чтения базы без установки SQLite-пакетов:

```sql
SELECT rank, title, year, rating, genres, director, url
FROM movies
ORDER BY rank;
```

Парсер прекращает работу с ошибкой, если IMDb блокирует запросы или отдаёт
неполный список, и не заменяет базу частичными данными. Повторите запуск позже.
